01. Síntese Executiva da Pesquisa

Sistemas físicos cujas interações pares decaem com a distância $r^{-\alpha}$ onde $\alpha \le d$ ($d$ sendo a dimensão espacial) são denominados sistemas com interações de longo alcance. Exemplos proeminentes incluem sistemas autogravitantes (astrophysical body dynamics), plasmas não-neutros e o Modelo Hamiltoniano de Campo Médio (HMF).

⚡
Não-Aditividade
A energia total de dois subsistemas não equivale à soma de suas partes. A energia de interface cresce com o volume, alterando as propriedades termodinâmicas fundamentais.
❄️
Calor Específico Negativo
No ensemble microcanônico, a perda de energia pode levar a um aumento de temperatura ($C_v < 0$), um comportamento perfeitamente estável em sistemas não-aditivos.
🔀
Inequivalência de Ensembles
Os ensembles Canônico e Microcanônico produzem previsões termodinâmicas distintas no limite termodinâmico devido a regiões não-côncavas na entropia $S(E)$.
🌀
Relaxação Violenta & QSS
Partindo do fora do equilíbrio, o sistema passa por um rápida relaxação violenta para um Estado Quase Estacionário (QSS), cuja vida útil diverge com o número de partículas $N$.
Descoberta Central sobre a Hipótese Ergódica:
Para sistemas autogravitantes com o Fator de Kac ($1/N$), o sistema é sempre ergódico para $N$ finito, embora exija tempos de observação consideráveis. Caso o Fator de Kac não seja utilizado, o tempo necessário para atingir a ergodicidade diverge com o crescimento de $N$ (isto é, o sistema torna-se estritamente não-ergódico no limite de Vlasov $N \rightarrow \infty$).

02. Fundamentação Teórica & Dinâmica

A evolução no espaço de fase $\Gamma$ para um sistema de $N$ partículas sob um potencial gravitacional é regida pela Hamiltoniana:

$$H = \sum_{k=1}^{N} \frac{p_k^2}{2} + \sum_{k < l}^{N} V(r_k - r_l)$$

A densidade de probabilidade no espaço de fase $\rho(p, q, t)$ obedece ao Teorema de Liouville ($\frac{d\rho}{dt} = 0$), garantindo a conservação do volume no espaço de fase sob transformações canônicas.

Teorema do Virial e Calor Específico

Para potenciais homogêneos de grau $k+1$, o Teorema do Virial estabelece que $\langle T \rangle = \frac{k+1}{2} \langle V \rangle$. Em sistemas autogravitantes 3D ($k=-2$), temos $E = -\langle T \rangle$. Como a temperatura é proporcional à energia cinética ($T \propto \langle T \rangle$), a capacidade térmica microcanônica resulta em: $$C_v = \frac{\partial E}{\partial T} \propto \frac{\partial (-\langle T \rangle)}{\partial T} < 0$$

03. Inequivalência de Ensembles & Construção de Maxwell

No Modelo do Anel (Ring Model), $N$ massas idênticas situam-se em um anel de raio unitário sujeitas a atração gravitacional regularizada por um parâmetro $\epsilon$:

$$V_\epsilon(\theta_i - \theta_j) = -\frac{1}{\sqrt{2}} \frac{1}{\sqrt{1 - \cos(\theta_i - \theta_j) + \epsilon}}$$

Diferente dos sistemas de curto alcance, onde uma região convexa na entropia $S(E)$ permite a separação e coexistência de duas fases através do "envelope côncavo" da Construção de Maxwell tradicional, em sistemas de longo alcance a não-aditividade impede a coexistência de fases em uma interface física. Isso gera um salto descontínuo na energia no ensemble canônico (calor latente) mantendo uma transição de fase de 1ª ordem sem coexistência.

04. Métodos de Análise da Ergodicidade

Para determinar rigorosamente se um sistema dinâmico satisfaz a Hipótese Ergódica ($\text{Média Temporal} = \text{Média de Ensemble}$), este trabalho emprega três metodologias independentes:

Calcula-se a média temporal das velocidades e posições de cada partícula individual $k$ até o tempo $t$: $$\overline{p}_k(t) = \frac{1}{n} \sum_{j=0}^{n} p_k(j \Delta t)$$ Em um sistema ergódico, o desvio padrão tomado sobre todas as $N$ partículas deve decair assintoticamente para zero: $$\sigma_{\overline{p}}(t) = \sqrt{\frac{1}{N} \sum_{k=1}^{N} \overline{p}_k(t)^2 - \langle \overline{p}(t) \rangle^2} \longrightarrow 0 \quad (t \rightarrow \infty)$$

Discretiza-se o espaço dos momentos em células de tamanho $\Delta p$. Computa-se a distribuição de frequência dos tempos de permanência $t_s$ das partículas nessas células. Distribuições ergódicas gaussianas apresentam cauda truncada, enquanto sistemas fracamente não-ergódicos exibem caudas em lei de potência sem escala de tempo característica.

Utiliza a transformada de Fourier do processo estocástico $Y(n)$ para avaliar Ergodicidade $Q(n)$ e Mixing $E(n)$: $$Q(n) \equiv \frac{1}{n} \sum_{k=1}^{n-1} E(k) \longrightarrow 0 \quad (\text{Ergodicidade})$$ $$E(n) \equiv \langle e^{i[Y(n) - Y(0)]} \rangle - |\langle e^{i Y(0)} \rangle|^2 \longrightarrow 0 \quad (\text{Mixing})$$

05. Resultados Numéricos & Espaço de Fase 2D

Para simulações autogravitantes bidimensionais, a Hamiltoniana com Fator de Kac é dada por: $$H = \sum_{k=1}^{N} \frac{p_k^2}{2} + \frac{1}{2N} \sum_{k, l=1}^{N} \ln(|r_k - r_l| + \epsilon)$$

06. Algoritmos Numéricos & Computação de Alto Desempenho

Para a integração temporal exata das trajetórias sem erros seculares de energia, foi utilizado um Integrador Simplético de 4ª Ordem de Yoshida. As simulações de ensembles Monte Carlo do Modelo do Anel foram desenvolvidas em Fortran 90/95, enquanto a simulação em paralelo de $N$-corpos 2D utilizou arquitetura CUDA em GPUs.

Trecho do Integrador Simplético de Yoshida em C (Apêndice A.1 da Tese)

/* Integrador Simplético de 4ª Ordem (Yoshida 1990) - Apêndice A.1 */
void yoshida_step(double *r, double *p, double *f, double dt, int n) {
    const double b0 =  0.675603595979828813;
    const double b1 = -0.175603595979828813;
    const double d0 =  1.351207191959657630;
    const double d1 = -1.702414383919315250;

    // Etapa 1
    for(int i=0; i<2*n; i++) {
        p[i] += b0 * dt * f[i];
        r[i] += d0 * dt * p[i];
    }
    compute_forces(r, f, n); // Atualiza forças gravitacionais

    // Etapa 2
    for(int i=0; i<2*n; i++) {
        p[i] += b1 * dt * f[i];
        r[i] += d1 * dt * p[i];
    }
    compute_forces(r, f, n);

    // Etapa 3
    for(int i=0; i<2*n; i++) {
        p[i] += b1 * dt * f[i];
        r[i] += d0 * dt * p[i];
    }
    compute_forces(r, f, n);

    // Etapa 4 final
    for(int i=0; i<2*n; i++) {
        p[i] += b0 * dt * f[i];
    }
}

07. Conclusões & Referências Bibliográficas

Principais Contribuições da Tese:

  1. Demonstração de que sistemas autogravitantes 1D e 2D com Fator de Kac são ergódicos e obedecem ao critério de mixing para qualquer $N$ finito.
  2. Comprovação de que a escala de tempo para ergodicidade em sistemas autogravitantes 2D é independente do número de partículas $N$, graças ao caráter confinante do potencial logarítmico.
  3. Dedução formal da Construção de Maxwell em interações de longo alcance no Modelo do Anel, comprovando a ausência de coexistência de fases físicas e a inequivalência de ensembles.
